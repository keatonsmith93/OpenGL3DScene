# OpenGL3DScene
Scene of my choosing recreated from a picture into a 3D Scene

Software Design Approach
I approach software design by breaking a project into clear, manageable components and identifying the relationships between them. For this 3D scene, that meant analyzing the real‑world objects on my mantle, determining which primitives could represent them, and planning how transformations, lighting, and materials would work together. This project strengthened my ability to think in terms of modular design—treating each object as its own system with properties, behaviors, and dependencies.
New Design Skills Developed
Working on this scene helped me develop stronger spatial reasoning and object‑composition skills. I learned how to combine simple primitives into more complex models, such as constructing the Golden Snitch or shaping the Sorting Hat. I also gained a deeper understanding of how lighting design influences mood and realism, and how material properties can dramatically change the appearance of an object.
Design Process Followed
My design process followed an iterative cycle:
- Start with a reference photo of my mantle
- Identify the major objects and their primitive components
- Block out rough shapes and positions
- Refine proportions, materials, and lighting
- Adjust based on visual feedback and testing
This iterative approach allowed me to gradually improve accuracy and visual quality without getting stuck on early details.
Future Applications of These Design Tactics
The same tactics—breaking problems into components, iterating, and refining based on visual or functional feedback—apply to any future software or graphics project. Whether designing user interfaces, game environments, or data visualizations, this structured approach helps maintain clarity and adaptability.

Program Development Approach
I approach development by starting with a functional baseline and then layering features on top of it. For this project, I began with basic object rendering, then added transformations, lighting, materials, and scene composition. I focused on building a stable foundation before introducing complexity.
New Development Strategies Used
I used several new strategies while building the 3D scene:
- Incremental testing after each major change
- Using transformation hierarchies to position objects accurately
- Experimenting with lighting models to achieve specific visual effects
- Adjusting material properties to simulate metal, wood, parchment, and fabric
These strategies helped me understand how small adjustments can significantly impact the final render.
Role of Iteration
Iteration was essential. Each milestone required revisiting earlier decisions—tweaking lighting, adjusting object scale, or refining materials. This repeated refinement helped me develop a more polished and cohesive final scene.
Evolution of My Coding Approach
Throughout the milestones, my approach shifted from simply “making things work” to thinking more intentionally about structure, readability, and realism. I became more comfortable experimenting, debugging visual issues, and using incremental improvements to reach a final polished result.

This project reinforced how programming and creativity intersect to produce meaningful digital experiences.
